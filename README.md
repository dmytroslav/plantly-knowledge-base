# Plantly — довідник фітозахворювань

Опублікована версія довідника для мобільного застосунку Plantly.

| файл | призначення |
|---|---|
| `manifest.json` | номер версії, дата, SHA-256, кількість статей і перелік міток |
| `knowledge_base.json` | статті довідника |

Файли створює `knowledge_base/publish.py`; вручну їх не редагують.
Застосунок приймає нову версію лише після звірки контрольної суми й
покриття всіх міток моделі.
